# P05: passive test-dossier review

This is an experimental importer and a separately implemented competent script for a narrow OpenHTF JSON profile: one phase and one scalar inclusive-range measurement. Four exports were produced by the real framework from **synthetic values**; no physical test is represented. The framework is not imported or regenerated by these tests.

```sh
python -B tests/run_matrix.py --output results/primary_fresh
python -B review/counterexamples.py --out results/adversarial_fresh
```

Use absent output directories and Python3.11+ (stdlib only). The primary matrix expects30/30 outcomes for each program. The22 post-hoc cases include coherent forged input, malformed/nonfinite data and a capacity-dependent nesting case. Agreement can depend on parser capacity; a difference is not automatically an advantage. The second command writes a summary; the root CI runner explicitly checks its expected counts.

`READY_FOR_REVIEW` is a documentary state, including a complete measured FAIL. Coherent forgery can still yield documentary PASS. `material_release_authorized` remains false: hashes do not prove instrument origin, calibration, or authenticity. No human-time gain, market demand or physical validation is established.

The prepared pilot under `evidence/PILOTE_TERRAIN_PRET.txt` is **PREPARED_NOT_RUN**:4 development missions,12 held-out missions, at least3 families,2 operators and separate arbitration. Measure full preparation/review/correction/maintenance costs before asserting savings. No radio corpus or derivative under CC BY-NC-SA is included. This code does not operate instruments or publish customer data.
